An AI receptionist on your website that answers questions and books appointments 24/7 — the same AI as on your WhatsApp, Instagram and Messenger.

== Description ==

* Chat bubble on every page — answers questions, books, moves and cancels appointments.
* Online booking page with the [nextreply_booking] shortcode.
* One-click connect to your NextReply account; no code to paste.

Requires a NextReply account (free trial at https://app.nextreply.io). The chat widget loads from NextReply's servers and sends visitors' chat messages there to be answered.

== Installation ==

1. Plugins → Add New → Upload Plugin → choose nextreply.zip → Install → Activate.
2. Open NextReply in the menu → Connect to NextReply → log in.
3. Done. Add [nextreply_booking] to a page for online booking.
